# 騎乘分析（bike-visualization-and-analyses）

把 Strava 匯出的 GPX 丟進網頁，就能得到：

- **單趟分析**：摘要、依速度上色的地圖、海拔與速度剖面、自動分段、每公里用時、依坡度分組的速度、停車紀錄、回放動畫。
- **兩趟比較**：自動對齊兩趟路線並剔除不能比較的路段，產生分段比較、四層疊圖（海拔／速度／速度差／累計時間差）、速度差地圖、依坡度比較，以及可調整的**虛擬對騎**動畫。

所有計算都在瀏覽器裡進行，GPX 不會上傳到任何地方。

## 使用方式

1. 打開網頁 https://evantilu.github.io/bike-visualization-and-analyses/ ，按「選擇 GPX 檔案」，可以一次多選。
2. 清單勾一趟＝單趟分析，勾兩趟＝比較（預設日期較新的一趟是藍色，可以對調）。
3. 想留存就按「列印／存成 PDF」。

建議把 GPX 都放在同一個資料夾（例如 iCloud Drive），每次從那裡多選。

## 方法重點

- **移動時間**：長時間沒有移動的時間間隔視為自動暫停，不計入，和 Strava 的移動時間一致；停在原地但仍在記錄的秒數會計入。
- **對齊**：以「最完整落在另一趟路線上」的那一趟為參考路線；另一趟的每個點投影到參考路線上（25 m 內、行進方向一致、只能往前推進）。去回同一條路、繞路、支線都能分辨。
- **可比路段**：自動剔除原地起步的前 200 m、終點前 150 m、任一趟離開路線又回來的地方（依該趟減速／加速範圍自動加寬），以及只有一趟騎過的路段。
- **計時**：參考路線上每 10 m 一個計時點，兩趟各自用移動時間通過；虛擬對騎把各段接起來，時間差連續累計。
- **扣除停車影響**：停車點前 100 m 到後 130 m 改用該騎士停車前 500 m 的配速推算。
- **GPS 飄移**：連續兩個以上明顯過快的 1 秒位移（定位延遲後補上）會被標記，該範圍的逐點速度不採用。

## 限制

- GPX 只有位置、海拔、時間（若有心率、踏頻、功率、溫度會自動顯示）。沒有功率時無法分辨進步來自車還是人；風向、氣溫、路況也會影響。
- 爬升用本工具的演算法計算，可能和 Strava 差幾公尺。
- 分段差距 5 秒以內可視為打平。

## 開發

純靜態網頁，沒有建置步驟：

```
npm run serve     # http://localhost:8000
npm test          # 回歸測試（需要 private/fixtures/ 裡的測試 GPX，這個資料夾不會進版控）
```

- `js/gpx.js` GPX 解析　`js/ride.js` 單趟前處理　`js/compare.js` 兩趟對齊與計時
- `js/single.js`、`js/comparison.js` 報告　`js/player.js` 回放／虛擬對騎　`js/maps.js`、`js/charts.js` 地圖與圖表
